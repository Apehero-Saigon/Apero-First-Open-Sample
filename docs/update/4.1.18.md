## 1. App Update

**Step 1 — Provide AppInfo**

In `FirstOpenActivity` (extend from `AstronexFirstOpenActivity`), implement `onProvideAppInfo()`:

```kotlin
override fun onProvideAppInfo(): AppInfo = AppInfo(
    packageName = BuildConfig.APPLICATION_ID,
    versionCode = BuildConfig.VERSION_CODE,
    versionName = BuildConfig.VERSION_NAME,
)
```

**Step 2 — Trigger soft update check**

Call `AppUpdateManager.showSoftUpdateDialogIfNeed()` at the appropriate time. The SDK does not call
this automatically.

> Note: Place this call at the end of your BottomSheet or Dialog content so the update dialog is not covered by the BottomSheet or Dialog.



```kotlin
// Activity
class MainActivity : AppCompatActivity() {
    override fun onResume() {
        super.onResume()
        AppUpdateManager.showSoftUpdateDialogIfNeed(this)
    }
}

// Fragment
override fun onResume() {
    super.onResume()
    AppUpdateManager.showSoftUpdateDialogIfNeed(requireActivity())
}
```

## 2. NativeAdContentPreferredObFullScr (optional)

> Note: This integration is optional. Treat it as an available option and integrate it only when requested by the Product Owner.

A composable that displays the SDK's preloaded `nativeOnboardFullscreen` ad (loaded during the FO
splash flow) on the main screen. When the primary ad is unavailable, it automatically falls back to
a dev-provided ad group.

### Parameters

| Parameter         | Type             | Description                                                                                          |
|-------------------|------------------|------------------------------------------------------------------------------------------------------|
| `fallbackAdGroup` | `NativeAdGroup`  | Your own ad group shown when the SDK's primary ad is unavailable. The SDK auto-loads it on fallback. |
| `layoutId`        | `@LayoutRes Int` | XML layout used to render the native ad.                                                             |
| `modifier`        | `Modifier`       | Standard Compose modifier.                                                                           |

### Usage

```kotlin
NativeAdContentPreferredObFullScr(
    fallbackAdGroup = AdsProvider.nativeOpen,
    layoutId = R.layout.layout_native_ad,
    modifier = Modifier.fillMaxWidth(),
)
```
